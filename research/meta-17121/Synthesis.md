# Reproducing the bounded circuit search

The four rows from the distributed project's step `L-meta-17121` appear in `seed_tables.json` in the assigned order. Each of the eleven input words has 32 bits. A gate takes the bitwise AND or OR of two earlier words. The target is 16383. The question asks whether an admissible trace with at most 18 gates can produce it. A new word is admissible when no earlier word has a subset of its erroneous bit positions, where error is XOR with the target.

`exact_synthesis.py` produces a Boolean satisfiability instance (DIMACS) and the decoding information for any one row. One example is `python exact_synthesis.py --case 0 --gates 18 --out case0.cnf`. A live prefix models from one to eighteen gates; each live gate chooses one operation and two different earlier operands. The gate equations compute every distinct column of the truth table. The last live gate must equal the target. Every earlier live gate must have a later reader. The input zero is still included when checking whether an earlier word dominates a new one. An operand equal to zero is unnecessary in a minimum circuit, since AND with zero yields zero and OR with zero returns the other operand.

## Why the ordering and dominance restrictions preserve existence

Take a minimum circuit reaching the target on the samples, delete unused gates, and put the target at the output. Idempotence removes gates with identical operands. For each gate order its two operand indices increasingly. Repeatedly schedule the ready gate having the smallest possible larger operand index, relative to the indices already assigned. The newly assigned gate index exceeds the indices of every operand of every gate that was already ready. A newly enabled gate therefore cannot decrease the sequence of larger operand indices. This proves completeness of the encoding's ordering restriction.

Write u ⪯ v when the error positions of u are a subset of those of v. Both bitwise gates preserve this order in either operand. At a target-one coordinate an improvement replaces a zero by a one. At a target-zero coordinate an improvement replaces a one by a zero. If an earlier word dominates a later gate, redirect every use of that gate to the earlier word and delete the gate. This can only improve the final word, and the exact target already has no errors. This contradicts minimum size. The argument applies in any topological ordering of a minimum circuit. Together these observations show that a satisfying model exists precisely when there is some admissible circuit of the requested size or smaller.

## Verification and outcomes

`test_synthesis.py` compares the encoding with exhaustive enumeration for small truth tables and checks four known 19-gate circuits, including independent replay of the official dominance condition. `star_upper.py` reconstructs those four circuits. `run_synthesis.py` makes four separate SAT calls using CaDiCaL 1.9.5 through PySAT and records one JSON result per case. Each SAT result is decoded and checked against the original 32-bit inputs, in the original numbering. UNSAT is a solver verdict. A formal lower bound would also require a checked proof of unsatisfiability and a verified translation, or a separate proof in the project's Lean format. A search that reaches its time or conflict limit returns UNKNOWN.

The initial hosted run uses a 25-minute search limit, on a public runner, with pinned Linux package hashes. The workflow runs the smoke tests before starting the searches. `python -m unittest -v test_synthesis` is sufficient to check the encoding with the corresponding platform's PySAT wheel installed. The two independent formula and single-level arguments, including arithmetic and graph verifiers, are in `FormulaLowerBound.md` and `SingleLevel.md`.
